# Data outline (from Erwin's brother, 2026-11-21)

Backtest case: Texas City Y, 22 Mar 2014.

- Currents: HYCOM-TSIS GOMb0.01 reanalysis — https://www.hycom.org/data/gomb0pt01/gom-reanalysis
- Winds: ERA5 10 m — https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview (needs free CDS account)
- Stokes drift: WAVERYS — https://data.marine.copernicus.eu/product/GLOBAL_MULTIYEAR_WAV_001_032/description (needs free CMEMS account)
- Validation of forcing: TABS buoy F — https://tabs.gerg.tamu.edu/tglo/tabsqueryform.php?buoy=F ; NDBC 42035 — https://www.ndbc.noaa.gov/station_history.php?station=42035 ; NOAA CO-OPS API — https://api.tidesandcurrents.noaa.gov/api/prod/
- Trajectory scoring: NOAA IncidentNews 8741 — https://incidentnews.noaa.gov/incident/8741 ; NTSB MAR-15/01 — https://www.ntsb.gov/investigations/AccidentReports/Reports/MAR1501.pdf
- Not usable for March 2014: NGOFS2, GBOFS, GOFS 3.1 analysis, Texas HF radar.
